# Wizarding

Wizarding is a puzzle game about math, where you can concatenate blocks in order to solve equations and open paths to a new room.

You can find the working game on its itch.io page https://artiarana.itch.io/wizarding


## What does it use

- Godot 4.4
- Nathan Hoad's Dialogue manager for managing dialogs.
- It has a deprecated connection to supabase.
